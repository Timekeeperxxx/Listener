## Findings 与修正

没有待解决的 P0/P1/P2 项。

1. [P2，已修复] 音乐库与我的收藏复用了喜欢的音乐和最近播放概览。移除重复入口，推荐、发现、收藏使用不同内容结构；收藏默认直接显示歌曲表。
2. [P2，已修复] 原搜索中的歌曲未受收藏范围限制。统一从当前入口的数据范围搜索；搜索“范特西”时，发现为 10 首歌曲及 1 张专辑，收藏仅为 3 首已喜欢的歌曲。
3. [P2，已修复] 原歌单数据混用了精选与个人创建属性，收藏页只显示喜欢的音乐。区分公开歌单、创建歌单和已收藏歌单，并加入可取消的歌单收藏。
4. [P2，已修复] 中等窗口样式会隐藏最后一张歌单。移除隐藏规则；800 px 宽时公开歌单共 4 张，实际可见 4 张。
5. [P2，已修复] 页面切换可能沿用前一页滚动位置。导航、分类和详情切换时回到内容顶部，实测标题顶部为 113 px，低于 82 px 顶栏。
6. [P2，已修复] 歌单分类的筛选可能影响整个收藏搜索。搜索忽略分类筛选；选择“我收藏的”后搜索“工作”，仍可找到创建的“工作”歌单。

## 五项视觉检查

- **字体与排版**：保留原字体体系；仅使用功能名称、歌曲名称和数量。检查中英文曲名、四个分类计数及标题，无标语回流。
- **间距与布局**：推荐保留概览和五列专辑；发现为目录网格；收藏为曲目表。385 px 宽时四个分类全部可见，最后一项右边界约 298.4 px，无页面水平溢出。
- **颜色与材质**：保留白蓝 / 深灰橙主题，夜间强调色实测 `#f2a45d`，背景实测 `rgb(20, 22, 25)`。顶部玻璃底座和滑动选中胶囊继续随三个入口移动。这是 CSS 网页效果，不是 macOS 原生材质 API。
- **图片与图标**：复用项目素材和 Lucide，浏览器无损坏图片。歌曲行播放状态与悬停按钮继续互斥，实测正在播放行可见图标为 1 个。
- **内容与文案**：三个入口反映不同数据范围；无“慢慢听”“听点新的”“换一种心情”“反复心动”。页内标记设计预览，外观面板说明不连接 QQ 音乐。

## 1. Root Cause

原型在音乐库和收藏页复用了同一概览，歌曲搜索又直接从全部曲目取值，导致入口命名与实际内容范围不一致。此次从数据范围和页面结构同时修正。

## 2. Modified Scope

修改 `Preview.vue` 的导航、目录/个人数据范围、搜索、歌单收藏和滚动位置；修改 `style.css` 的推荐区、歌曲操作区、分类与响应式规则；提取实际复用的 `TrackTable.vue`、`AlbumCards.vue`、`PlaylistCards.vue`，保留已有交互语义。更新 README、验收记录和两份单文件 HTML。

## 3. Failure Policy

这是使用内嵌演示数据的内存交互原型。无 QQ 请求、数据库或登录成功状态；没有把演示数据称为已接入的完整在线乐库。空收藏显示明确空状态，空歌曲集合不启动模拟播放。素材和引用的示例曲目必须存在，构建缺少入口时仍然直接报错。

## 4. Added Defensive Branches

未增加推测性的空值检查、默认值、重试、兼容分支或静默回退。新增的条件分别代表用户选中的入口、分类、收藏状态和搜索状态，属于本次明确要求的产品行为。滚动容器在 UI 交互后必然挂载，不加入吞错或额外空值回退。

## 5. Explicit Non-Changes

没有修改 QQ 接口、凭据、SQLite、正式客户端入口、自动更新源或安装的 macOS 应用；没有外网部署或推送 GitHub。原型不播放真实音频，不调用真实个性推荐；收藏仅保留在当前页面会话。
