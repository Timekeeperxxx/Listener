# Listener 前端设计预览

独立 HTML 交互原型，顶部按“推荐—发现—我的收藏”分工，保留最近播放、唱片网格与底部播放栏，重新设计品牌排版、唱片卡片、分段导航和视觉层级。

- 推荐：精选歌单、最近播放和专辑推荐。
- 发现：浏览、搜索演示目录的全部歌曲、专辑、歌手和公开歌单，不受收藏限制。
- 我的收藏：喜欢的歌曲、收藏的专辑与歌手、自己创建及收藏的歌单。默认打开喜欢的歌曲，搜索也仅覆盖收藏和个人歌单。

当前目录是内嵌演示数据：129 首歌曲、11 张专辑、6 位歌手。推荐内容是预先挑选的演示内容，未接入 QQ 在线目录或个性推荐服务。

- 日间：白色、雾蓝、亮蓝。
- 夜间：深石墨灰、暖橙色。
- 顶部：半透明玻璃底座、滑动选中胶囊、边缘高光与轻回弹；尊重系统“减少动态效果”。
- 文案：功能名称、数量与操作状态，已移除标语。
- 歌曲：单击选中；双击、Enter 或行首按钮播放。行首序号/播放状态与悬停播放/暂停按钮互斥显示。
- 交互：歌单、专辑、歌手、收藏、搜索、队列、歌词展开/关闭、字号和主题切换。

## 预览与导出

仓库已有依赖时运行：

```sh
npx vue-tsc --noEmit -p prototypes/listener-next/tsconfig.json
node prototypes/listener-next/build.mjs
```

导出 `prototypes/listener-next/Listener.html` 和 `artifacts/design-preview/Listener.html`。字体、封面、图标、Vue、AMLL、样式与脚本均已内嵌，可直接用浏览器打开。图片与字体来源及许可保存在 HTML 的 `asset-credits` 元数据中。

本地网页预览：

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory artifacts/design-preview
```

访问 `http://127.0.0.1:4174/Listener.html`。

这是界面交互演示：不连接 QQ 音乐、不播放真实音频，收藏只保留在当前页面会话。正式桌面应用继续使用原入口。
