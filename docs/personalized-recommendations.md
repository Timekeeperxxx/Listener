# QQ 音乐个性化推荐接入记录

## 1. 原因与证据

原推荐页由 `searchPlaylists('华语流行')` 获取公共搜索结果，并没有读取账户的个性化推荐。QQ 推荐信息流在匿名访问时也返回成功，但没有当前账户的每日推荐卡片，因此不能把接口成功等同于登录成功。

已用现有钥匙串会话完成真实只读验证：每日推荐返回当天 30 首完整歌曲；猜你喜欢每批实际返回 5 首，连续请求的批次不同；每日推荐歌曲能取得 HTTPS 播放地址，歌手和专辑 ID 完整。测试仅输出数量、日期和布尔结果，不输出凭据、播放 URL 或私人歌单内容。

请求参数依据 QQ 自身的[推荐页脚本](https://y.qq.com/n3/wk_v20/entry/recommend.chunk.498dd3a28.js?max_age=6048000)，响应字段通过真实请求核实。

## 2. 修改范围

- `src-tauri/src/recommendations.rs`：验证登录、读取 `RecommendFeed/get_recommend_feed` 中 `subtype:510` 的当天动态歌单，再经现有 `CgiGetDiss` 读取完整歌曲；猜你喜欢使用 `MbTrackRadioSvr/get_radio_track`。
- `src-tauri/src/lib.rs`、`models.rs`：增加主窗口命令、每日推荐返回类型，以及现有 SQLite 缓存中的账户专属日推记录。
- `src/lib/api.ts`、`src/types.ts`：增加两个原生命令的类型和调用，接入已有的登录过期续期流程。
- `src/stores/discovery.ts`：分开保存公共发现与私人推荐，隔离加载状态、错误和请求序号。
- `src/components/HomeView.vue`、`src/redesign.css`：推荐页使用每日30首、最近播放和猜你喜欢；换一批只刷新猜你喜欢。公共分类歌单继续位于发现页。跨北京时间午夜检查日推，窗口重新可见时也检查。
- `src/demo/main.ts`：为独立 HTML 演示补齐新增接口的演示数据；正式构建继续使用真实原生命令。
- `src-tauri/examples/recommendation_probe.rs`、`tests/discovery.test.ts`、`tests/recommendation-view.test.ts`：真实接口检查和针对性测试。

## 3. 失败处理

登录失效、请求失败、字段变化、当天日推尚未生成、歌单不完整和数据库错误都会明确返回错误。推荐页显示重试操作，不使用公共搜索或收藏冒充账号推荐。

猜你喜欢刷新失败时保留当前账户上一批歌曲，同时显示失败原因。每日推荐刷新时清空旧内容，避免把旧日期显示成今天。缓存按账户读写，仅接受北京时间当天的数据；手动刷新绕过缓存。

## 4. 新增判断的依据

- 每日卡片存在性、唯一性、数字 ID、生成日期和必需字段校验：依据实际 QQ 响应结构，避免误取公共歌单或旧日推。
- 歌单总数、分页状态、重复 MID 和已有歌曲标识校验：日推必须完整且能够沿用原播放及目录导航。
- 猜你喜欢字段、空结果校验及保序去重：依据实际返回的 `tracks` 数组；缺字段与空结果分别显示错误。
- 账户快照和响应序号判断：沿用项目账户隔离约定，阻止切号后的旧响应覆盖当前账户。
- 可选缓存、有效期及日键判断：缓存不存在时正常请求上游，缓存异常直接报错，不隐藏存储失败。
- 前端 `try/catch`：将真实失败呈现为可见错误状态；不把错误转换为成功的空列表。
- 日期检查和计时器清理：支持跨日及组件卸载，避免重复请求与后台计时器残留。
- 两个新增读取命令复用已有的一次登录续期重试；没有新增其他重试、备用接口或默认成功行为。

## 5. 范围边界

没有新增服务器、API Key 配置、大模型或第三方凭据转发。凭据继续只保存在钥匙串；推荐缓存复用现有 SQLite，不引入另一份存储。没有改写 QQ 的推荐排序，没有新增听歌行为上报，也没有把 Listener 的本地播放历史宣称为已参与 QQ 推荐。

本次构建开发版用于验证，没有发布 GitHub Release 或覆盖 `/Applications` 中的安装版。AutoMix 属于独立的音频处理功能，尚未实现。

## 6. 验证

- 前端测试：109 项通过，覆盖账号切换后的旧响应、过期日推、失败展示、换一批、单击选中/双击播放、每日完整队列、跨午夜刷新和卸载清理。
- Rust 单元测试：42 项通过，2 项既有在线扫码测试忽略；覆盖卡片筛选、日期边界、日推完整性和真实歌曲标识。
- `npm run build`、`npm run build:demo` 通过；开发版 macOS app 构建通过。
- 真实账户接口检查：30 首日推、每批 5 首猜你喜欢、换批结果不同、日推歌曲播放地址可用、目录 ID 完整。
- 客户端已恢复真实账户并显示每日推荐和 5 首猜你喜欢；已观察到开发版的歌曲播放与歌词渲染。原生库中已写入当天的 30 首日推缓存，验证时未输出账户 ID 或歌曲清单。
- 单击选中、双击播放、日推详情入口与完整队列、换一批行为通过组件测试验证；真实日推详情读取和换批通过原生接口检查验证。未在原生 UI 中逐一重复操作，也未执行收藏或下载写入测试。
- 未验证其他 QQ/微信账户、真实系统跨午夜运行和离线环境。跨日与账户隔离已通过自动测试验证。
