# Listener 0.3.0

本次把统一搜索、完整歌手队列、歌手/专辑收藏、macOS 桌面控制、歌词偏好和应用维护接入实际客户端，并使用 Timekeeperxxx/Listener 发布更新。包含歌词首字左侧泛光被裁切的修复。

## Root Cause

旧版搜索以歌曲为主，歌手详情的播放仅使用已读取页面；歌手和专辑缺少独立收藏。窗口关闭、快捷键、歌词偏好、缓存预算与在线更新没有形成完整的桌面流程。AMLL 每行的绘制裁切只留出 0.2em，而单词泛光可到 0.3em，导致首字左侧出现硬边。

## Modified Scope

- 统一搜索歌曲、歌手、专辑及公开歌单，采用 QQ 返回的分页位置；最近 20 条搜索按账户保存。
- 歌手播放与随机播放先读取所有曲目。歌曲结束前 20 秒预先读取下一首音源并缓冲；切歌复用已准备的音频，队列和账户变化使旧预加载失效。
- 收藏歌手和专辑，提供“我的收藏”入口。收藏保存到本机 SQLite，按 QQ 账户隔离。
- 菜单栏控制、关窗后台播放与四个可配置全局快捷键。⌘Q 保存后完全退出；快捷键重复、格式无效或系统占用均显示错误。
- 歌词字号、行距、译文、音译持久保存；每首歌词可独立微调时间，并与全局偏移叠加。关闭前等待未完成的设置写入。
- 显示歌词缓存、下载和资料文件占用，设置歌词缓存预算、按账户清理缓存。
- 接入 GitHub Releases 更新清单，校验更新包签名及签名绑定的版本。更新密钥保存在仓库之外。
- 移除歌词行的绘制裁切，保留布局隔离、播放器边界和屏外歌词移除。文字位置和换行宽度不变，泛光可以自然向外延伸。

## Failure Policy

网络和业务错误不会变成“空列表”或“已是最新版本”。分页失败保留已读取内容，完整歌手读取失败时不播放部分列表。预加载失败不会打断当前歌曲，实际切歌重新获取音源。收藏和单曲偏移在持久化成功后才更新。保存失败时显示错误，关闭操作等待成功写入。

## Added Defensive Branches

保留并扩展已有的账户所有权和异步请求编号检查；增加预加载媒体所有权、版本签名、设置范围、缓存预算以及快捷键注册冲突检查。系统热键更换失败时恢复之前的绑定；恢复失败会明确要求重新打开应用。未增加写操作自动重试或伪造数据回退。

## Explicit Non-Changes

QQ 云端歌单和歌曲红心仍走现有写入确认流程。歌手/专辑收藏仅保存在当前 Mac。HTML 演示不连接真实账户或音源。只发布 Apple Silicon；应用仍为 ad-hoc 签名，尚未做 Apple Developer ID 公证。预加载减少等待，不承诺音频采样级无缝播放。

GitHub OAuth 授权缺少 `workflow` 权限，原有 Actions 工作流保持原样，新的检查流程以 `docs/ci/check.yml` 模板提供。播放器源码完整替换为本次 macOS 实现。

- Rust 35 项测试通过、2 项真实扫码测试按既有设置忽略；Clippy 所有目标以 `-D warnings` 通过。
- 桌面前端及独立 HTML 演示构建通过。
- 匿名真实 QQ 四类搜索均返回有效结果；公开查询“周杰伦”返回歌曲 1000、歌手 11、专辑 494、歌单 299。可用 `cargo run --manifest-path src-tauri/Cargo.toml --example search_smoke` 复现，数量随 QQ 目录变化。
- 网页验证了真实 Adele 搜索、完整详情、收藏和完整曲目读取。QQ 搜索曾返回 2001，界面显示实际错误，手动重试后成功。
- 原生账户恢复和歌曲播放已验证，恢复过程未要求读取或输出凭据。
- 更新包已生成带版本绑定的签名；本地应用签名及 DMG 校验通过。安装包约 6 MB。

已在本机安装包含泛光修复的 0.3.0。用相同 AMLL 渲染器和同一句 Whoah-oh 做前后对照，修复后左侧泛光无硬边。原生设置中快捷键保存成功，关闭窗口后应用仍保持运行，可从 Finder 用 ⌃⌥M 唤回主窗口，播放状态继续保持。菜单栏各项及另外三组全局快捷键尚未逐项验收。会员/地区、到期续期和所有云端写入组合，以及较旧 macOS 仍需要对应账户或设备验收。GitHub 正式 Release 和匿名更新清单已验证，五个发布文件的 GitHub SHA-256 均与本地一致，应用内检查返回“已是最新版本”。一次匿名更新包下载在 30 秒内未收到数据；下载、安装并重启的完整升级流程尚未实测，需在更高版本发布后验证。
