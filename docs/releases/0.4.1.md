# Listener 0.4.1

歌曲“更多”改为在按钮旁展开的小菜单。“添加到”和“下载”使用相邻子菜单，背景页面继续可以操作；点击外部、滚动、切换页面或按 Esc 可收起菜单。

## Root Cause

原 `TrackActions.vue` 使用 `dialog.showModal()`，把歌曲操作做成了居中的阻塞弹窗。歌曲行只传递曲目，没有传入触发按钮的位置，因此无法将菜单定位到按钮旁。

## Modified Scope

- `TrackList` 传递歌曲、当前列表和触发按钮；歌单、收藏、搜索、歌手及专辑页面逐层转发同一个菜单目标。
- `TrackActions` 改成带 ARIA 菜单语义的浮层，不创建模态 dialog、遮罩或背景 inert 状态。
- 提供播放/暂停、下一首、加入队列、喜欢、添加到歌单、下载和适用时的移除操作；复用现有播放器、QQ 写入及下载实现。
- 子菜单只列出可写的自建歌单。下载子菜单保留下载到本机和下载管理入口，使用原有音质设置。
- 菜单根据按钮和窗口尺寸定位：底部空间不足向上展开，子菜单靠近右侧时向左展开。保留白蓝/灰橙主题。
- 添加上下方向键、Home/End、向右方向键展开子菜单、向左方向键返回和 Esc 关闭；关闭时按交互场景恢复触发按钮焦点。
- 异步歌单写入、下载结果显示实际成功或错误；关闭菜单后错误仍可见。

## Failure Policy

歌单写入仍等待 QQ 确认，失败不会被标成已添加；下载成功仅以下载记录为依据。错误提示保持可见，用户可关闭或在下载管理中重试。账户切换会关闭菜单并使旧请求的提示失效；旧操作完成不会关闭后来打开的另一首歌曲菜单。

## Added Defensive Branches

新增判断对应明确 UI 状态：菜单关闭、空/正在加载的歌单、离线账户、下载进行中、窗口边缘与已移除的触发按钮。请求后的账户代次及菜单目标比较用于阻止过期提示和错误关闭。空歌单子菜单没有可聚焦项目时由面板接收焦点；列表后来加载完成后，方向键从首/尾项开始。没有增加网络自动重试、兼容性回退、默认成功或替代数据源。

## Explicit Non-Changes

未添加相似歌曲、MV、分享、购买等参考截图里的其他功能。QQ 权限、歌单写入、音源选择、下载文件与账户隔离逻辑不变。静态 HTML 原型不冒充正式客户端的真实操作。未发布 GitHub Release。
