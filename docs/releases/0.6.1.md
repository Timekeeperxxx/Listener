# Listener 0.6.1

macOS 的 Dock、Finder 和安装包统一使用 iPhone 版的蓝色六线声波图标。Mac 在「设置 → 外观」可以选择跟随系统，歌词交互和原生 iPhone 客户端的更新见 [0.6.0 发布说明](https://github.com/Timekeeperxxx/Listener/releases/tag/v0.6.0)。

- **macOS Apple Silicon**：在 Listener 中打开「设置 → 存储与更新 → 检查更新」，或下载 `Listener_0.6.1_aarch64.dmg` 安装。
- **iPhone（iOS 26.0+）**：下载 `Listener_0.6.1_iOS_Native.ipa`，通过 iLoader 签名安装。本次 iPhone 包同步了版本号。
