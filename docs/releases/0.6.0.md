# Listener 0.6.0

新增原生 iPhone 客户端，并把 iPhone 的歌词浏览和自动跟随体验带到 macOS。

## 安装

- **macOS Apple Silicon**：下载 `Listener_0.6.0_aarch64.dmg`，将 Listener 拖入「应用程序」。已安装版本也可通过应用内更新升级。
- **iPhone（iOS 26.0+）**：下载 `Listener_0.6.0_iOS_Native.ipa`，在 iLoader 里选择 **Import IPA** 并签名安装。

界面截图见 [项目 README](https://github.com/Timekeeperxxx/Listener#界面截图)。

## 原生 iPhone 客户端

- SwiftUI 界面使用系统 Liquid Glass 标签栏、迷你播放器和播放控件。全尺寸封面下可以预览当前句和下一句，歌词页会保持屏幕唤醒。
- QQ 授权、扫码和手机号登录入口共用 Rust 接口、系统钥匙串与本地资料库。AVPlayer 负责播放，并向锁屏和系统媒体控制提供曲目及进度。
- 支持查看歌曲、专辑和歌手详情，管理红心、歌单、播放队列和离线下载。列表提供搜索、排序与随机播放，日期排序取决于数据源是否提供日期。

## macOS 和 iPhone 歌词

- 浏览时清晰显示周围歌词。正在唱的那句继续逐字点亮，指到或触碰的其他句子可以整句提亮。
- 点击虚化的歌词会进入浏览。iPhone 同时展开进度条，再点清晰的歌词可以跳到对应时间。
- 停止浏览后，播放中的歌词在 2.5 秒后随下一句回正，最长等待 5 秒。回正和虚化同步开始，暂停时保留浏览位置。
- 长歌词会自动换行，译文紧跟原词。间奏显示三点动画，时间标注明确的长音可以轻微放大。

## 推荐与音乐库

- 推荐页展示每日 30 首、个性化歌曲、推荐歌单与 QQ 音乐排行榜。最近播放移到「我的收藏」。
- 歌单详情支持播放全部、随机播放和收藏。歌手歌曲可按热度或发行时间排序，专辑显示发行年份。
