# Listener 0.5.1

设置界面支持 macOS 通用的 `⌘,` 快捷键。

## Modified Scope

- `App.vue`：在全局键盘处理中识别 `⌘,`（Windows/Linux 上的 `Ctrl+,`），打开设置；设置已经打开时不重复创建模态窗口。
- `README.md`：操作表补充“打开设置 ⌘,”。
- 版本提升至 0.5.1。

## Verification

- 前端 142 项测试、Vue/TypeScript 检查和生产构建通过。
- Rust 49 项测试、Clippy 通过。
- 快捷键的原生按键监听仍需在安装后的窗口中确认；没有修改其他快捷键或设置数据。
