# Listener 0.4.9

修正会员/付费歌曲的 VIP 标记和播放权限提示。

## Root Cause

QQ 的歌曲 `pay` 字段中，会员歌曲可能只有 `pay_month: 1`，而 `pay_play` 仍为 `0`。原映射只检查 `pay_play`，导致《Sacrifice》这类歌曲在队列里显示为免费歌曲；实际播放时 QQ 返回 `104003`，界面却只提示“请重新登录”，让已登录用户误以为是会话失效。

## Modified Scope

- `qq.rs`：`vip` 同时检查 `pay_play` 和 `pay_month`，会员歌曲显示 VIP 标记。
- `qq.rs`：`104003` 的提示改为区分权益与登录：“会员或单独购买的歌曲需要对应权益；如果这是免费歌曲，请重新登录。”
- 新增 `pay_month` 映射测试，版本提升至 0.4.9。
