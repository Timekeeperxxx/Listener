# Listener 0.2.4 · QQ 线上乐库

日期：2026-11-04。已安装至 `/Applications/Listener.app`。

歌手和专辑现在直接读取 QQ 音乐线上数据。歌手支持真实头像、介绍、歌曲列表、发行专辑和分页；专辑支持封面、发行日期、公司、语言、流派、介绍和完整曲目。目录可按地区浏览，也可以搜索收藏之外的内容。

网页预览：[完整乐库演示](http://127.0.0.1:4173/demo.html#view=album&album=001fUMYh0xeX8Y)。启动命令为 `npm run demo`。网页的歌手、专辑及搜索读取 QQ 公开元数据，个人歌单、播放与歌词仍为界面演示；不发送账户 Cookie。`npm run build:demo` 生成前端资源，线上数据请求还需要开发服务器的 `/__qq` 代理，不能把构建目录当作离线完整乐库。

## 1. Root Cause：原因与证据

0.2.3 使用 `buildCatalog(library.catalogTracks)` 将已读取的个人歌曲按展示名称聚合，且 Track 丢弃了 QQ 返回的歌手与专辑 MID。因此，歌手作品数受收藏限制，歌手图可能只是歌曲封面，也无法读取线上简介或发行专辑。

本次先对 QQ 网关进行无账户公开接口验证，再实现原生调用。实测歌手目录返回 23782 位歌手；周杰伦返回 1013 首歌曲、43 张专辑；《叶惠美》返回 11 首曲目和 2568 字介绍。目录、歌曲和新碟的第二页与第一页不同，周杰伦的 43 张专辑已通过两页读全。数量是验证时接口返回值，之后可能变化。

接口参数参考项目维护者的[QQ API 实现](https://github.com/Yyyangshenghao/simple-music/blob/master/server/lib/qq-client.ts)和[专辑接口定义](https://github.com/L-1124/QQMusicApi/blob/main/qqmusic_api/modules/album.py)，并以本机实际响应确认：搜索请求使用模块名作为请求键；专辑详情参数为 `albumMId`；新碟翻页使用 `start`。这些请求均发往 QQ 官方网关。

## 3. Failure Policy：失败处理

登录、权限、账户切换、网络、QQ 业务码及必要字段错误继续显式返回。前端显示出错原因并提供重试；第二页失败保留已经成功读取的内容和下一页位置，不把错误显示为“没有作品”。

歌手歌曲和发行专辑按需分页；专辑详情根据 QQ 返回的总数持续读取，读完才交付完整曲目。接口在总数尚未读完时返回空页，会报不完整列表错误。内容范围以 QQ 当前能够返回的数据为准。

## 4. Added Defensive Branches：新增分支及依据

| 分支 | 依据与实际处理 |
| --- | --- |
| MID、地区、页码、搜索字数验证 | 外部输入边界。拒绝无效标识与未支持的地区，不拼接猜测的身份。 |
| 响应业务码、对象、数组和数量检查 | QQ 实测响应结构。必要字段缺失直接报协议错误；不转换为默认成功列表。 |
| 空中间页、搜索页跨度检查 | 专辑和歌曲需要完整分页；实测搜索一页有 19 条可见结果，但下一页仍从 20 开始。使用服务端页位置，防止重复或漏页。 |
| 搜索 2001 最多五次、间隔 300ms | 同一有效查询实测出现临时 2001，参考实现也采用此界限。只针对该业务码；最后失败显式返回，不扩大到认证或其它错误。搜索采用验证成功的 Chrome 请求头。 |
| 旧 Track 缺少 `artists` / `albumMid` | 已发布 0.2.3 的播放队列、历史和下载确实未保存这些字段。反序列化为空身份，点击时按精确歌曲 MID 补查；匹配不到歌手或专辑时明确提示，不按名称猜测或选择第一个歌手。 |
| 可选图片、日期、类型、语言、流派和公司 | QQ 不同接口确实会缺少部分展示字段。真实 MID 可生成 QQ 头像/封面 URL；其余缺失保持空白或说明暂无介绍，不生成虚构资料。 |
| 发行专辑的署名没有完整歌手 ID | 该接口只返回 `singerName` 字符串。保留原始署名文本，进入专辑详情后再使用完整歌手引用，避免把合作歌手全部绑定到当前歌手 MID。 |
| 初始空状态与当前详情空值 | 页面在请求完成前没有详情，显式显示加载；只有请求成功且列表为空时才显示无结果。 |
| 前端各请求的 `try/catch` | 目录、详情、下一页与旧歌曲补查均将异常写入对应可见错误状态，不吞掉失败。 |
| 请求编号、重入与缓存检查 | 测试覆盖旧搜索、旧歌手下一页和退出账户后晚到的响应。仅同一歌手/专辑已成功加载时复用结果；加载中阻止重复“更多”请求，账户变化清空目录状态。 |
| HTML 代理与独立适配器 | 浏览器实测直接转发本地 Origin 被 QQ 拒绝为 104400；代理使用 QQ 来源头。公开目录请求不携带账户 Cookie；必要结构和请求失败显式提示。示例数据不参与桌面请求失败处理。 |

未加入跨来源备用曲库、静默空列表、匿名账户替代或模糊名称合并。

## 5. Explicit Non-Changes：边界

未重构认证、音频源、下载、收藏写入或数据库权属；保留原有主窗口和账户校验。只为已发布 Track 数据增加已知字段兼容，不改旧记录的真实身份。

歌词逐字动画、手动浏览后的延时回中、歌词页展开/关闭和底栏布局保持现有实现。本轮没有宣称新的实测帧率。

本次按照已有部署授权更新本机 macOS Apple Silicon 版本，没有发布外网网站。旧版应用与 ZIP 备份位于 `artifacts/releases/0.2.4/`。正式桌面构建不包含演示歌单和播放模拟。
