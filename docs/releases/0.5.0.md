# Listener 0.5.0

重做设置界面，采用 macOS 系统设置式的侧边栏与分组卡片布局。

## Root Cause

原设置面板是 600 px 宽的四个标签页，播放、歌词、快捷键和存储排成较长的单列；主题只能在顶栏切换，歌词字号/偏移等控件缺少预览和重置入口，界面层级与 macOS 26 的视觉语言不一致。

## Modified Scope

- `SettingsPanel.vue`：改为“账户 / 外观 / 播放 / 歌词 / 快捷键 / 存储与更新”六个分类，左侧图标导航、右侧分组卡片。
- 账户：头像、昵称、连接状态、退出/重新连接、同步说明；演示模式不再显示假的连接按钮。
- 外观：浅色/深色分段选择，接入现有主题状态；歌词流动背景开关。
- 播放：音质、自动衔接、预加载、关窗后台播放、定时停止、迷你播放器、桌面歌词和下载管理。
- 歌词：新增三行歌词预览；字号、行距、译文、音译、全局及本首偏移，并提供重置按钮。
- 快捷键：启用开关、四个按键捕获框、恢复默认与应用；保留注册冲突错误。
- 存储与更新：三张用量卡片、缓存上限与清理、版本检查、更新说明和下载进度。
- `App.vue`：设置对话框改为由面板管理标题与关闭按钮，并把主题传入/传出。
- `redesign.css`：增加完整的 macOS 风格设置样式、深色主题、窄窗口和减少透明度适配。

## Failure Policy

原有存储、更新、快捷键和账户命令不变；错误继续显示在对应分类。演示模式明确标注为网页演示，不伪造登录或存储数据。主题切换立即生效并保存在当前 Mac。
