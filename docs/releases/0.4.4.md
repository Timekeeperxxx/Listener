# Listener 0.4.4

歌词页补全专辑信息：元信息显示可点击的专辑名称，封面右上角增加发行年份徽标。

## Root Cause

歌词页只展示歌曲名和歌手，`Track.album` 没有渲染；歌曲对象也没有专辑发行时间。原有 `get_album_detail` 会读取整张专辑的曲目，不适合只为一枚日期徽标调用。

## Modified Scope

- `catalog.rs`：新增轻量 `album_meta`，只请求 `GetAlbumDetail` 并返回真实 `CatalogAlbum`。
- `lib.rs`：新增 `get_album_meta` 命令，复用当前账户快照和失效检查。
- `api.ts`：增加 `albumMeta` 调用，并纳入登录续期读取集合。
- `LyricsView.vue`：按 `albumMid` 读取专辑元信息，缓存后显示专辑名称；封面右上角使用玻璃质感小徽标，只显示发行年份，完整日期保留在提示中。专辑名称可点击进入专辑详情。
- `App.vue`、`style.css`：歌词页转发专辑点击事件；增加封面容器、徽标和专辑链接布局，窄窗口下徽标仍贴合封面右边缘。
- `demo/main.ts`：演示入口使用公开专辑详情补齐同一字段。

## Failure Policy

专辑元信息属于封面和歌词之外的附加展示；读取失败时不伪造发行时间，也不替换歌曲身份，只隐藏徽标。歌曲名、歌手和歌词状态继续按原流程显示错误。请求使用专辑 MID 校验和请求序号，切歌后旧结果不会写入当前歌曲。
