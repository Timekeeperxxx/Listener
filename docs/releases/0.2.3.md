# Listener 0.2.3 · macOS Apple Silicon

发布日期：2026-11-04。

## 1. Root Cause

本轮歌手、专辑页与歌词交互此前已在网页中完成，已安装的 macOS 应用仍是 0.2.2，需要正式构建并更新。

## 2. Modified Scope

同步更新 npm、Cargo、Tauri 和设置界面的版本号为 0.2.3。构建包含歌手/专辑浏览、名称跳转、歌词左侧整体布局、展开/收起动画、手动浏览后延时恢复自动对齐。

安装位置：`/Applications/Listener.app`。

安装包：`src-tauri/target/release/bundle/dmg/Listener_0.2.3_aarch64.dmg`，约 5.8 MB；应用约 8.84 MiB。

## 3. Failure Policy

构建、应用签名及安装后文件一致性均检查通过后才交付。未修改 QQ 登录、网络和持久化的错误处理，没有把演示数据作为真实账户数据的备用结果。

## 4. Added Defensive Branches

未增加运行时空值检查、默认成功状态、重试、兼容分支或静默降级。旧版应用已备份到 `artifacts/releases/0.2.3/Listener-0.2.2-backup.zip`，压缩包完整性检查通过。

## 5. Explicit Non-Changes

未修改用户资料目录、钥匙串或云端歌单；未加入演示图片、示例歌曲或模拟播放。歌手和专辑目录仍按真实资料库中已经读取的歌曲聚合，不代表 QQ 完整曲库。本次为本机 macOS 更新，没有发布外网网页。

## 6. Verification

- 57 项前端测试全部通过。
- TypeScript、Vite 和 Rust 发布构建通过，生成 arm64 应用与 DMG。
- 构建产物及安装后的应用均通过 `codesign --verify --deep --strict`。
- DMG 通过 `hdiutil verify` 和 SHA-256 校验。
- 安装版 Info.plist 显示 0.2.3，可执行文件与构建产物逐字节一致，SHA-256 相同。
- 已从 `/Applications/Listener.app` 启动。原有 QQ 账户、630 首收藏及歌单恢复；原生界面显示 546 个专辑条目、364 个歌手条目，并观察到真实歌曲《Misty Mystery》的播放状态及同步歌词。
- 本轮未重跑下载、云端歌单写入及多种系统版本测试；具体歌词延时和取消条件的自动化验证及网页运行记录见上一轮前端验证文档。
