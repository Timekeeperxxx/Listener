# Listener 0.4.0

新版界面采用“推荐—发现—我的收藏”导航，保留现有 QQ 登录、播放、逐字歌词、下载和桌面控制。此版本用于本机 macOS Apple Silicon 安装。

## Root Cause

确认的 HTML 设计尚未进入正式客户端，旧客户端的音乐库和收藏入口混用了个人歌单与完整目录。歌曲单击也会直接播放，和用户要求的选择行为不同。

## Modified Scope

- 正式客户端加入原创布局、白蓝日间主题、灰黑橙色夜间主题、顶部滑动玻璃标签和唱片卡片。外观选择在当前 Mac 保存。
- 推荐页读取 QQ 的新碟和分类公开歌单，并展示实际最近播放；推荐属于公开目录精选，未声称是 QQ 个性推荐算法。
- 发现页直接浏览、搜索 QQ 歌手、专辑、公开歌单及歌曲。歌手和专辑详情继续通过真实 ID 读取介绍、图片、完整曲目与分页资料。
- 我的收藏集中显示喜欢的歌曲、已收藏专辑/歌手及个人歌单；搜索只覆盖这些内容。喜欢的歌曲复用原有分页请求，完整元数据与红心状态在同一次读取中确认。
- 曲目、最近播放与队列采用单击选中；双击、Enter 或行首按钮播放。当前歌曲的行首按钮可暂停/继续，声波与播放/暂停图标互斥。
- 保留 QQ 扫码登录、播放恢复、逐字歌词、队列维护、创建/编辑歌单、下载、设置及菜单栏能力。下载入口移入我的收藏及设置。
- 版本号更新为 0.4.0，生成带版本签名的更新包、清单和 DMG。

## Failure Policy

真实接口失败显示错误和重试按钮，不用演示资料或个人收藏替代公开目录。分页失败保留已读取的数据，旧请求不能覆盖新分类或新账户。收藏元数据在读取成功或写入确认后更新。登录、凭据与播放仍由原 Rust/SQLite/钥匙串路径处理。

## Added Defensive Branches

新增公开目录请求编号，用于阻止切换分类或退出账户后的旧响应写回；分页期间沿用既有的加载与剩余页面检查。外观没有保存值时默认日间模式，是本版明确的默认主题。没有增加网络自动重试、账号回退、双重持久化或默认成功状态。

本机替换应用先暂存并校验新 bundle，保留旧版 bundle；若切换失败则恢复旧版。该回滚只处理安装中真实可能发生的重命名失败，不掩盖构建或签名错误。

## Explicit Non-Changes

未变更 QQ 认证、曲源权限、歌词解析和同步时钟、自动更新公钥或更新地址。本次不推送源码、不创建 GitHub Release。账户资料不随安装包或源码提交，演示入口与正式客户端继续隔离。
