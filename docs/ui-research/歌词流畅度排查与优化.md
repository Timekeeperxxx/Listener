# 歌词流畅度排查与优化

验证日期：2026-11-04。目标：改善逐字高亮和歌词换行的连贯性，保留原有视觉效果。

## 1. Root Cause：已确认的问题与证据

原实现每次 `requestAnimationFrame` 都把音频时间写入 Pinia 的响应式状态，再经 Vue 属性传给 AMLL 的 Vue 包装组件；包装组件另有动画循环。歌词需要逐帧更新，而整个播放器界面不需要以相同频率重新计算。包装组件还把渲染器保存在 Vue `ref` 中，使渲染器内部对象进入响应式处理。

原生 WebView 的优化前采样已经达到约 60 次回调/秒，歌词时间也约 60Hz，弹簧和缩放已开启。因此，没有证据说原版本被限制在 30fps，也不能把主观卡顿全部归因于平均回调频率。

本次消除的是每帧经过全局响应式状态和包装组件传递时间的开销。尚未测量 GPU 实际呈现的帧数，不能仅凭 `requestAnimationFrame` 宣称完全消除掉帧。

## 2. Modified Scope：修改范围

- `src/components/SyncedLyrics.vue`：直接使用 AMLL 核心接口；渲染器放在普通变量中，每帧先读取音频时间，再调用 `setCurrentTime` 和 `update`。保留弹簧、缩放、模糊、译文、音译及点击歌词跳转。暂停时继续处理排版；隐藏和卸载时取消动画循环。
- `src/components/LyricsView.vue`：接入新的歌词组件，保留封面、背景和现有布局。
- `src/stores/player.ts`：提供直接读取音频时间的 `readLyricTime`；普通界面的动画采样改为至少间隔 100ms。暂停、拖动、原生 `timeupdate` 等事件仍立即同步，所以实际界面更新次数并非严格固定为 10Hz。
- `tests/player.test.ts`、`tests/synced-lyrics.test.ts`：验证逐帧时钟与普通界面更新分离、恢复进度、暂停排版、译文切换、隐藏和卸载后的资源释放。
- `package.json`、`package-lock.json`：增加仅供组件测试使用的 `happy-dom`，不进入 macOS 应用运行包。

## 3. Failure Policy：失败处理

未更改登录、权限、播放地址、歌词解析和持久化的错误处理。真实请求失败仍显示原有错误；没有把失败转换成空歌词或成功状态。临时采样代码已从产品源码移除。

## 4. Added Defensive Branches：新增分支说明

- `readLyricTime` 在音频已有 `src` 时读取媒体时钟；尚未加载音频的恢复暂停状态使用已恢复的进度。该状态原本就存在，并有专门测试覆盖。
- 歌词窗口不可见时不安排动画帧；重新可见时用当前音频时间对齐。此分支用于现有窗口可见性规则和资源释放。
- 没有新增重试、兼容旧数据分支、异常吞掉后的默认值或静默降级。

## 5. Explicit Non-Changes：范围边界

没有修改 QQ 音乐账户、歌单、下载、缓存归属和播放持久化机制；没有新增生产环境配置、身份兜底、双写或第二套播放时钟。音频本身仍是时间的来源。没有删除用户喜欢的歌词视觉效果。

## 6. Verification：实际验证

- 全部 49 项前端测试通过，包括 5 项本次增加的时钟和组件生命周期测试。
- `npm run mac:build` 通过：包含 `vue-tsc` 类型检查、Vite 发布构建、Rust 发布构建和 DMG 校验。
- 发布应用通过 `codesign --verify --deep --strict`。
- 已更新 `/Applications/Listener.app`；安装版与本次构建的可执行文件 SHA-256 一致。
- 真实 QQ 音乐歌曲《Dangerously》在原生 WebView 显示并推进歌词；保存了可访问性采样和原生画面。
- 正式安装版已恢复 QQ 账户及歌单，并播放《真的爱你》。原生界面验证：暂停后歌词保持显示；暂停时按右方向键，播放位置从 107.7 秒变为 112.7 秒；关闭译文后歌词仍保持显示；之后恢复译文并继续播放。

优化后采样：背景动画开启，59 行歌词，连续约 10 秒共 600 个动画回调；60.0 次/秒，回调间隔 p95 为 18ms，超过 25ms 的间隔为 0；歌词时钟更新 60.0Hz，时间增量 p95 为 19ms；播放及窗口焦点在采样中均为 100%。弹簧、缩放和模糊均开启。

这些数值是回调和时钟数据，不是系统合成器实际呈现帧数。优化前后保存的采样片段并非严格一致的歌曲和时间段，因此不据此计算提升百分比，也没有宣称 CPU 或 GPU 使用率下降了多少。窗口被遮住或隐藏时会暂停动画，后台画面不能用于判断前台流畅度。长时间运行、不同显示器刷新率和用户的实际体感仍需后续观察。
